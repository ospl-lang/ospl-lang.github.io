linux/bsd/unix installation

  • install rustup, use your system package manager if possible. if your system package manager does not have rustup in its lists, execute this command in a terminal curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  • you may need to run rustup toolchain install stable
  • run git clone https://github.com/ospl-lang/osmium to obtain ospl's latest source code
  • change directory into the this folder: cd osmium/
  • run cargo install --path 'crates/ospl-toolchain'
  • if you use bash, edit $HOME/.profile and add the line export PATH="$PATH:$HOME/.cargo/bin". if you prefer a different shell, edit your $PATH accordingly (i assume you know how to do that if you're the type to use a different shell)
  • log out and log back in, you should now have the ospt command.

windows installation (windows 10 or newer)

  • open a command prompt and run winget install -e --id Microsoft.VisualStudio.2022.BuildTools. you may need to accept a license agreement by pressing y.
    During installation select "desktop development with C++"
    ensuring to include "MSVC toolchain (latest x64/x86)" and "Windows 10/11 SDK"
  • also install git: winget install -e --id Git.Git
  • setup environment variables
    • windows+r, open sysdm.cpl
    • go to the 'advanced' tab
    • click on 'environment variables...'
    • click on 'path' in the 'user' section
    • click on 'edit...'
    • add %USERPROFILE%\.cargo\bin
  • go to win.rustup.rs to obtain the file rustup-init.exe
  • run this program
  • open a command prompt, ensure you are in your home folder
  • git clone https://github.com/ospl-lang/osmium
  • cd osmium
  • cargo install --path 'crates/ospl-toolchain'

macos installation

macos is untested!

  • basically the same steps as unix, just editing .zprofile instead of .profile
  • ensure you have xcode xcode-select --install
  • curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  • rustup toolchain install stable
  • git clone https://github.com/ospl-lang/osmium
  • cd osmium
  • cargo install --path 'crates/ospl-toolchain'
  • echo 'export PATH="$PATH:$HOME/.cargo/bin"' >> $HOME/.zprofile
